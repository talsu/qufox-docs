# Vendored fonts

| File | Family | Source | License |
| --- | --- | --- | --- |
| `geist-mono-latin.woff2` | Geist Mono (variable, Latin subset) | Google Fonts, `geistmono/v6` | SIL Open Font License 1.1 |
| `space-grotesk-latin.woff2` | Space Grotesk (variable, Latin subset) | Google Fonts, `spacegrotesk/v22` | SIL Open Font License 1.1 |

These are the brand fonts the qufox design system names in its tokens
(`--font-mono-family`, `--font-display`). design.qufox.com loads them from Google
Fonts; the engine serves its own copy so sites work offline and make no
third-party requests.
